# Code Canvas

Create beautiful, downloadable code images for documentation, posts and presentations.

A working utility that processes data locally in the browser. No accounts, API keys, or server file storage.

## Run

Node.js 22 or newer.

```sh
npm install
npm run build
npm run dev
```

## Features

- Editable code with line numbers and basic syntax highlighting
- Background, padding, font size and window controls
- PNG export at 2× resolution

## Embed

Use `?embed=1&theme=light` (or `dark`) for the compact homepage demo. Theme follows the operating system by default, with an optional saved preference.

## Deployment

Vercel serves the generated `dist` directory.
